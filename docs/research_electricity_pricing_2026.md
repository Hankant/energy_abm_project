## 二、季节性电价与峰谷分时

### 2.1 季节划分

多数省份将一年划分为**夏季标准**与**非夏季标准**，或**丰水期/枯水期**。

| 地区 | 夏季标准 | 非夏季标准 |
|------|----------|------------|
| 广东、湖南等 | 5-10月 | 1-4月、11-12月 |
| 四川（地方电网） | 6-10月（丰水期） | 11月-次年5月（枯平水期） |
| 上海、北京 | 7-9月（制冷） | 11月-次年3月（采暖） |

### 2.2 夏季 vs 非夏季电价差异

以**广东广州**为例：

| 档次 | 夏季标准（元/kWh） | 非夏季标准（元/kWh） |
|------|-------------------|---------------------|
| 第一档 | 0-260度：0.5889 | 0-200度：0.5889 |
| 第二档 | 261-600度：+0.05 | 201-400度：+0.05 |
| 第三档 | 601度以上：+0.30 | 401度以上：+0.30 |

**夏季第一档电量上限（260度）比非夏季（200度）多30%，实际电费支出显著降低。**

### 2.3 峰谷分时电价（典型值）

| 时段 | 典型电价（元/kWh） | 说明 |
|------|-------------------|------|
| 峰段 | 0.5680 | 8:00-22:00 |
| 谷段 | 0.2880 | 22:00-次日8:00 |
| 尖峰 | 平段×1.2-1.7 | 极端天气/用电高峰期 |

**安徽**季节性高峰浮动：
- 1月、7月、8月、9月、12月：高峰上浮84.3%
- 其他月份：高峰上浮74%
- 低谷下浮61.8%

## 三、南北方电价差异分析

### 3.1 冬季取暖：核心差异

| 地区 | 冬季取暖方式 | 冬季电费影响 |
|------|-------------|-------------|
| **北方** | 集中供暖（暖气） | 供暖季电费极低（几乎不用空调/电暖器） |
| **南方** | 分散式电暖器/空调 | 冬季电费激增，月均200-600元 |

**典型案例：**
- 北方（北京）：冬季有集中供暖，家庭电费主要用于生活用电，月均约100元
- 南方（上海/浙江）：冬季无集中供暖，空调+电暖器月均电费可达400-600元

### 3.2 夏季制冷：共性特征

南北方夏季空调用电均大幅攀升，但南方持续时间更长（5-10月 vs 7-9月）。

| 地区 | 夏季空调负荷占比 | 夏季电费增幅 |
|------|-----------------|-------------|
| **北京** | 约40%（夏季最大负荷） | 相比春秋季翻倍 |
| **浙江** | 约40%（全社会用电负荷） | 暑期居民用电量302.7亿度 |
| **上海** | 约35-40% | 户均同比增长38% |
| **江苏** | 约33% | |

### 3.3 全年电费结构对比

| 季节/地区 | 北方典型（北京） | 南方典型（上海） |
|-----------|-----------------|-----------------|
| 春（3-5月） | 低（≈45元/月） | 低（≈50元/月） |
| 夏（6-9月） | 中高（≈150-200元/月） | 高（≈200-300元/月） |
| 秋（10-11月） | 低（≈50元/月） | 中（≈80-100元/月） |
| 冬（12-2月） | 低（≈100元，有供暖） | 高（≈300-600元，无供暖） |

### 4.3 ABM模型空调用电参数建议

基于上述调研，建议以下参数范围：

```python
# 空调基础用电参数（夏季基准，假设100元/月基础电费）
AC_SUMMER_RATIO_NORTH = 0.30   # 北方夏季空调占用电量比例（占基准）
AC_SUMMER_RATIO_SOUTH = 0.45   # 南方夏季空调占用电量比例（更高，湿度大）

# 季节系数（相对于基础电费的倍数）
SEASONAL_MULTIPLIER = {
    "spring": 1.0,      # 春秋季
    "summer": 1.5,      # 夏季（北方）
    "summer_south": 2.0, # 夏季（南方，空调使用更早更长）
    "autumn": 1.0,      # 秋
    "winter_north": 0.3, # 冬季（北方，有供暖）
    "winter_south": 2.5, # 冬季（南方，空调制热）
}

# 温敏系数（温度每升高1℃，用电增幅）
TEMP_SENSITIVITY = 0.08  # 8%增幅/℃

# 极端天气阈值
EXTREME_TEMP_THRESHOLD = 35  # 摄氏度，超过后用电激增
```

### 4.4 温度与用电量关系（上海研究）

## 五、政策工具模拟建议

基于电价结构，模型可模拟以下政策场景：

| 政策类型 | 对空调用电的影响 | 建模方向 |
|----------|----------------|---------|

| **阶梯电价** | 抑制高耗电行为 | 累进加价阈值 |
| **补贴政策** | 降低"煤改电"成本 | 补贴系数 |
| **限电管控** | 极端情况强制削减 | 功率上限约束 |

## 六、数据缺口与后续调研建议

1. **各省详细分时电价表**：各地尖峰、深谷时段划分差异大，需获取2025年最新电网代购电价表
2. **农村电价**：部分农村地区执行不同标准（如湖南农村基准0.2元/度）
3. **热泵/空调能效比（EER/COP）分布**：影响实际耗电量
4. **收入层次差异**：高收入家庭空调拥有量和使用时长更高
