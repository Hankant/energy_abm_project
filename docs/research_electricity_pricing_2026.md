# 珠三角居民电价参数与空调用电参考数据

> 调研目的：为问卷电价计算提供本地化参数支撑
> 调研时间：2026年5月
> 适用范围：广州、深圳、佛山、东莞、珠海、中山等珠三角城市

---

## 一、珠三角电价概况

珠三角城市执行**广东省居民阶梯电价**标准，城市间差异极小（仅基金附加略有不同，可忽略）。

电价结构特点：
- **夏季模式（5-10月）**：第一档电量上限提高至260度（比非夏季多30%）
- **非夏季模式（1-4月、11-12月）**：第一档电量上限为200度
- **三档递增**：用电越多，单价越高，第三档比第一档贵约0.30元/度

## 三、阶梯电费计算示例

**示例1：广州用户，夏季月用电500度**
```
第一档：260度 × 0.5889 = 153.11元
第二档：240度 × 0.6389 = 153.34元
合计：306.45元
```

**示例2：深圳用户，夏季月用电700度（非极端案例）**
```
第一档：260度 × 0.6629 = 172.35元
第二档：340度 × 0.7129 = 242.39元
第三档：100度 × 0.9629 = 96.29元
合计：511.03元
```

**示例3：东莞用户，非夏季月用电350度**
```
第一档：200度 × 0.5802 = 116.04元
第二档：150度 × 0.6302 = 94.53元
合计：210.57元
```

## 四、季节系数与空调月用电量估算

### 4.1 珠三角季节划分

珠三角属亚热带季风气候，夏季长达**6个月（5-10月）**，空调使用期显著长于北方城市。

| 月份 | 气候特征 | 空调使用强度 | 建议季节系数 |
|------|---------|-------------|-------------|
| 1月 | 冬季（偶有寒潮） | 极少制热 | 0.3 |
| 2月 | 冬季 | 极少制热 | 0.3 |
| 3月 | 春季 | 偶有制冷 | 0.5 |
| 4月 | 春季 | 开始制冷 | 0.7 |
| 5月 | 初夏 | **强** | 1.2 |
| 6月 | 盛夏 | **强** | 1.5 |
| 7月 | 酷暑 | **极强** | 1.8 |
| 8月 | 酷暑 | **极强** | 1.8 |
| 9月 | 夏末 | **强** | 1.3 |
| 10月 | 夏末/初秋 | 中等 | 0.9 |
| 11月 | 秋季 | 极少 | 0.4 |
| 12月 | 冬季 | 偶有制热 | 0.3 |

> 季节系数定义：相对于"非空调季基准用电量"的倍数
> 例如：某户非空调季月用电200度，7月酷暑用电 = 200 × 1.8 = 360度

### 4.2 空调用电量实测参考

#### 4.2.1 单台1.5匹变频空调耗电量

| 场景 | 每小时耗电 | 每天10小时 | 每月（30天） |
|------|-----------|-----------|-------------|
| 额定制冷功率 | ~1.1度 | ~11度 | ~330度 |
| 变频节能运行（26°C） | ~0.4-0.75度 | ~4-7.5度 | ~120-225度 |
| 极端高温（35°C+）持续运行 | ~1.3-1.5度 | ~13-15度 | ~390-450度 |

> 数据来源：美的KFR-35GW实测（制冷功率750W）、太平洋电脑网评测

#### 4.2.2 不同能效等级空调耗电对比

| 能效等级 | 1.5匹额定制冷功率 | 每月耗电（每天8小时） |
|---------|-------------------|---------------------|
| 新一级能效（变频） | ~850W | ~200-280度 |
| 新三级能效（变频） | ~1000W | ~240-320度 |
| 老旧定频（耗电高） | ~1300-1500W | ~310-360度 |

> 注：变频空调达到设定温度后压缩机关闭或低频运行，实际耗电远低于额定功率

#### 4.2.3 温度每升高1°C的用电增量

**关键数据（来源：重庆电力部门实测）：**
> 当气温达到35°C以上时，每再升高1°C，全市用电负荷增加约**100万千瓦时**。

对于家庭层面的测算：
- 室内设定温度26°C，室外35°C vs 室外40°C时
- 空调耗电增加约**15%-25%**
- 极端高温天（日最高≥37°C）相比普通高温天（日最高32-35°C），空调耗电增加约**30%-50%**

## 五、空调用电增幅模型参数建议

### 5.1 极热天气用电增幅公式

基于上述调研，建议问卷中极热天气（连续7天/30天日最高≥35°C）用电增幅按以下公式估算：

```
月用电增幅 = 基准用电量 × 基础增幅率 × 空调数量系数 × 极端高温系数

其中：
- 基准用电量 = 用户填写的月用电量（或上月账单）
- 基础增幅率 = 0.15（珠三角夏季平均空调占用电量比例的1/3）
- 空调数量系数 = 1 + 0.12 × min(空调数量, 5)
- 极端高温系数 = 1.3（7天极热）或 1.5（30天极热）
```

**简化版（用于问卷展示）：**

| 空调数量 | 7天极热增幅 | 30天极热增幅 |
|---------|-------------|-------------|
| 1台 | ~20% | ~30% |
| 2台 | ~30% | ~45% |
| 3台 | ~40% | ~55% |
| 4台+ | ~50% | ~65% |

> 注：以上为基于调研数据的估算，实际值受使用习惯、房间大小、隔热性能影响较大

## 七、数据缺口与建议

1. **峰谷电价覆盖率**：深圳可选峰谷电价，实际选择比例不明，问卷暂不展示峰谷计算
2. **城中村合表电价**：部分珠三角城中村执行合表电价（~0.62元/度），与阶梯电价不同
3. **空调实际运行时长分布**：不同家庭差异极大（每天2-16小时），建议问卷收集"通常每天开多久"
4. **2025年是否有新电价调整**：目前未见广东省发改委发布新的调价通知，2024年数据仍有效
