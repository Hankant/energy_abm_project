# Liu et al. (2020) 问卷公开程度核验

## 核验结论

这篇论文没有附上一份独立、可直接施测的完整问卷，也没有公开受访者实际看到的中文题目版本。

论文正文第7页 Table 2（`The 16-item Scale Questionnaire Employed in this Study`）逐项列出：

- 态度（ATT）4题；
- 主观规范（SN）4题；
- 知觉行为控制（PBC）4题；
- 节能意愿（I）4题；
- 各题编码和反向计分标记。

正文说明题项最初以中文设计，随后进行回译和文化调整，但 Table 2 展示的是英文题项。论文没有提供原始中文措辞、完整人口统计问卷页面、电子问卷流程或补充问卷文件。

## 使用边界

- 可以表述为“正文公开了16个英文 TPB 测量题项”。
- 不应表述为“论文附有完整中文问卷”或“已取得原始施测问卷”。
- 若借鉴题项，需要自行进行中文翻译、回译、认知访谈和预测试，并明确标注为改编题。
