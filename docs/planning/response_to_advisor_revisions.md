# 关于项目修订建议的说明

## 

### 1. 需要提升研究问题的层级

原提案如果仅仅围绕“家庭对补贴和阶梯电价组合的反应”展开，确实容易落入离散选择实验、条件估值法和准实验分析已经较成熟处理的问题域。在这种情况下，LLM-ABM 的方法优势不充分，容易被质疑为“用复杂方法回答传统问题”。

因此，研究问题应进一步上移，至少需要纳入以下更适合仿真方法的问题：

- 极端气候超出历史经验包络后，家庭行为如何变化；
- 未采纳人群内部的实际应对组合是什么，而不仅仅把“不采纳”视为残差类别；
- 尚未真实部署的政策组合，其交互效应如何在行为层面体现；
- 家庭之间的政策传播、社会比较和说服机制如何影响扩散路径。

这意味着项目未来不能只回答“政策有没有效”，而要回答“政策如何通过家庭决策和社会互动机制发挥作用”。

### 2. 需要重构 LLM-ABM 的方法论论证

原提案若主要使用“角色扮演”“社交模拟”“推理可解释”这类一般性语言来支持 LLM-ABM，确实不够有力。传统 ABM 本身就长期处理社会互动问题，而 LLM 的所谓“推理能力”在研究上也存在争议。

因此，后续方法论论证应更具体，重点强调以下几项能力：

- 开放行动空间：允许家庭做出问卷和规则树未事先完全枚举的行为组合；
- 基于人格与情境的定性推理：在相同价格刺激下，不同家庭可能因风险认知、生活质量偏好和心理账户而产生不同应对；
- 生成式互动内容：邻里交流、经验传播和政策讨论不只是数值权重变化，还可能包含可影响判断的话语内容；
- 超出历史经验的反事实生成：在极端高温持续时间和政策组合都超出既有经验时，模型能够进行机制层面的探索。

但这些能力需要被落实为模型中的具体模块，而不能停留在概念层面。

### 3. 需要引入行为偏差和行为政策工具

这一点非常重要。原提案中的家庭决策如果只被建模为对金钱刺激作出反应的近似理性行为，确实忽视了大量与家庭能源决策高度相关的行为证据，例如：

- 现时偏差；
- 损失厌恶；
- 心理账户；
- 默认效应；
- 显著性与框架效应；
- 社会比较和规范压力。

同时，政策工具也不应仅限于补贴、碳税和阶梯电价等金融手段，行为型政策工具同样应被纳入，例如：

- 默认设置；
- 账单显著性提示；
- 社会比较反馈；
- 节能信息框架；
- 邻里采纳展示。

将这些内容纳入后，项目会更接近真实家庭行为，也更能与行为公共政策和能源行为文献形成对话。

## 二、需要调整或保留不同意见的建议

### 1. 关于地理范围：项目应坚持强地域性，而非直接扩展为跨国比较

修订版中“将项目拓宽为跨国比较设计”的建议，并不一定适合当前研究。

当前项目的目标本来就是具有强地域性质的机制研究。研究对象可以明确聚焦于中国，甚至进一步聚焦到珠三角地区。这个定位并不是局限，反而是一种研究设计上的主动选择，因为：

- 珠三角地区具有典型的极端高温情境和较高制冷负荷，是研究家庭能源适应与低碳转型的天然场景；
- 该区域收入差异、住房条件差异和设备保有差异明显，适合分析家庭异质性；
- 中国特定政策制度背景、家电更新政策和能源价格机制，决定了该研究本就具有鲜明的本土政策导向；
- 若强行做跨国比较，将大幅提高制度口径统一、家庭能源结构可比性和数据清洗的复杂度，反而可能削弱项目聚焦度。

因此，更合适的表述不是“本研究追求全球普适性”，而是“本研究定位为中国特定区域背景下的机制研究”。在此基础上，后续如有需要，再讨论外部推广性，而不是一开始就将问题扩展到跨国。

### 2. 关于原创问卷：不应完全退回为小规模质性访谈

修订版认为原创问卷的作用应被压缩到“人格基础”的小规模质性访谈。这一判断过于收缩了当前项目的数据基础。

如果项目继续坚持以中国特定区域为对象，那么原创问卷仍然是有价值的，原因在于：

- 问卷可以提供本地化家庭基线特征，包括收入、住房条件、设备保有量、平时用电行为和低碳偏好；
- 问卷中的情景模块可以直接测量极端天气和政策处理下的行为变化方向；
- 问卷可以为区域性的 Agent 群体校准提供更贴近研究场景的数据；
- 问卷能够服务于模型的内部验证，而不仅仅是人格素材采集。

当然，这并不意味着 1000 份原创问卷能够同时承担所有方法功能。更合理的表述是：原创问卷是本项目的核心本地化数据源，但它主要服务于群体校准、行为异质性识别和内部验证；若要进行更强意义上的外部效度检验，仍需结合外部统计数据。

### 3. 关于验证：前 500 / 后 500 的分样本检验是有意义的，但不应被误称为“外部验证”

这一点需要概念澄清。

若收集 1000 份问卷，完全可以采用前 500 份用于模型校准、后 500 份用于样本外检验，或者采用交叉验证方式。这种做法是有方法价值的，它可以检验：

- 模型是否只拟合了训练样本；
- LLM 驱动节点在同一总体中的样本外泛化能力；
- 参数化规则是否过拟合特定受访者。

但同时必须承认，这种做法属于内部验证或样本外验证，而不是严格意义上的外部验证。它不能单独证明模型对现实行为具有完全的外部效度。因此，更合理的处理方式是：

- 保留分样本验证，作为模型可信度的重要组成部分；
- 同时引入区域用电统计、高温天负荷变化、设备采用率或政策事实结果，作为外部合理性校验。

也就是说，修订版关于“自己的问卷不能定义性地提供外部验证”这一点是对的；但这并不意味着问卷无法承担内部验证功能。

### 4. 关于方法比较对象：应优先与传统 ABM 比较，而不是直接与 DCE 或条件估值争高下

这是最需要明确坚持的一点。

当前项目的算法设计并不是“用 LLM 取代所有传统方法”，也不是“用 LLM 直接替代 DCE、条件估值或准实验”。项目的真实方法结构是：

- 总体框架仍然是传统 ABM；
- 环境、网络、时间推进和宏观汇总机制仍然是传统 ABM；
- 只有部分关键行为节点由 LLM 驱动，以增强对复杂、开放式和互动性行为的表达能力。

在这种情况下，最自然、也最公平的比较对象不是 DCE 或条件估值，而应当是传统 ABM。真正需要回答的方法问题应当是：

> 在传统 ABM 已经是合适框架的前提下，引入 LLM 驱动的局部决策节点，是否能更好地表示复杂、开放式、非预设的家庭应对行为？

因此，本项目的方法贡献不应表述为“LLM 优于传统识别方法”，而应表述为：

- 传统 ABM 擅长表示结构和演化；
- 其弱点在于对开放式行为节点的表达能力有限；
- LLM 的作用是在这些节点上提供增强；
- 项目应将“纯规则 ABM”或“参数化传统 ABM”作为主要对比对象。

这种定位更符合当前项目的真实结构，也更容易建立方法上的合法性。

## 三、项目更合适的重新定位

综合以上讨论，本项目更合适的定位应当是：

> 本研究聚焦中国，优先以珠三角地区为情境背景，研究极端高温持续冲击下家庭能源适应与低碳转型机制。研究将以原创区域问卷为核心数据基础，结合情景实验识别家庭异质性与行为响应，并在传统 ABM 框架下引入局部 LLM 驱动节点，以增强对开放式应对行为、未采纳行为和社会互动机制的表达能力。项目的核心比较对象应是传统 ABM，而不是直接与 DCE、条件估值或准实验争夺同一问题域。

这种重新定位有几个优点：

- 保留了项目原本的区域性和政策相关性；
- 吸收了修订版关于研究问题升级和方法论加强的优点；
- 避免项目被推向一个过于庞大的跨国方法学工程；
- 使原创问卷、传统 ABM 和 LLM 增强三者之间的角色关系更清楚。

## 四、建议表达的折中立场


第一，修订版中关于研究问题层级、方法论论证和行为机制扩展的建议，原提案在这些方面确实需要加强。

第二，项目的研究目标是强地域性的机制研究。

第三，原创问卷并不应被完全边缘化。它虽然不能单独提供强外部效度，但仍然可以承担区域群体校准、行为异质性识别和内部验证功能。

第四，项目的算法本质上是“传统 ABM + 局部 LLM 增强”，因此方法比较对象应优先是传统 ABM，而不是将项目错误地置于“LLM 对抗 DCE”的框架中。

第五，在方法表述上，将项目定位为：

> 不是用 LLM 取代传统识别方法，而是在传统 ABM 已经适合处理动态系统演化的前提下，使用 LLM 增强对复杂行为节点的表达能力。
