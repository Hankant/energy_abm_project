# 从宏观 Policy Mix 到微观家庭：问卷与 LLM 驱动的 ABM 方法更新

## 1. 研究目标和价值

本研究是一项方法论更新。目标是把宏观层面的 policy mix 理论转化为微观家庭能够感知并响应的政策情境，再用 ABM 模拟不同家庭的长期选择及其群体结果。

现有 policy mix 研究能够分析价格、补贴、信息、规制和保障措施之间的互动，却很少说明这些工具进入家庭以后如何产生差异化响应。现有居民 ABM 能够模拟节能意愿和行为，却通常把政策简化为若干强度变量，缺少 policy mix 理论中的工具组合、互动、时序和实施约束。

Yue 等（2020）已经将问卷、神经网络和 ABM 连接起来，为本研究提供了直接基础。但该研究有两处可以继续推进。第一，心理特征如何生成初始意愿、个体问卷如何映射到 Agent，以及神经网络的样本外有效性都没有充分说明。第二，政策模拟主要采用“单个变量取最大值”或“所有有利变量同时取最大值”，没有依据 policy mix 理论设计工具互动、实施顺序、预算和公平约束。这种“最优政策”是参数上界，不是真实政策组合。

本研究在两个部分做出贡献：

1. **政策组合设计**：依据 policy mix 理论，把价格、补贴、信息、规制和公平保护设计为具有现实单位、交互关系和实施顺序的政策情境；
2. **居民模型设计**：用问卷直接识别家庭在政策情境中的选择，用 LLM 在结构约束和经验参数范围内处理政策语义、多目标权衡、记忆和社会互动。

这项研究值得做，因为宏观政策效果最终取决于家庭是否能够响应、愿意怎样响应以及由谁承担成本。缺少微观行为基础，政策组合模型只能比较假定规则下的结果；缺少 policy mix 理论，居民模型只能比较若干孤立政策变量。本研究把这两个缺口放入同一个可验证框架。

```text
公共数据：人口、住房、设备、基线用电
问卷数据：政策选择、行为阈值、心理差异、社会影响
                           ↓
结构约束 + 经验选择模型 + LLM 决策模块
                           ↓
居民 ABM：重复决策、网络互动、设备更新和政策组合模拟
```

## 2. 为什么需要问卷

### 2.1 公共数据只能建立家庭结构

人口统计、CRECS、用电记录和设备数据可以提供收入、家庭人口、住房面积、设备保有量和基线用电。这些变量适合初始化 Agent，也可以校准总体用电和设备结构。

但公共数据通常不能识别以下参数：

| 参数 | 对 ABM 的作用 |
|---|---|
| 补贴与惩罚敏感度 | 决定不同政策工具引起的行为变化 |
| 可接受回本期 | 决定家庭何时投资高能效设备 |
| 额外支付意愿 WTP | 决定政策补贴与私人投入的关系 |
| 舒适度底线 | 决定高温下家庭能够减少多少用电 |
| 政策信任 | 决定家庭是否相信补贴、节能收益和政策承诺 |
| 社会影响敏感度 | 决定邻里采用能否引发扩散 |
| 补贴与惩罚的不对称反应 | 决定相同金额的奖励和损失是否产生不同效果 |

如果这些参数全部由文献均值或研究者假设，居民异质性只是表面上的人口差异，行为机制仍然是统一规则。问卷的主要作用是识别这些无法直接从公共数据得到的条件响应。

### 2.2 问卷应直接测量政策情境下的选择

Yue 等（2020）先用11个心理输入生成初始节能意愿，再用意愿、主观规范和政策环境预测四类节能行为：

```text
心理特征 → 节能意愿 → 政策条件下的行为
```

这条路线证明了问卷可以驱动 ABM，但存在两个模型问题。论文没有完整报告11个心理变量到初始意愿的映射；两阶段预测还会累积误差。一般节能意愿较强，并不等于家庭愿意在高价格、长回本期或住房受限的条件下购买设备。

它的政策设计也较弱。政策变量由问卷量表表示，单项政策模式把一个变量调到最有利值，所谓最优模式则把全部有利变量设为最高值。该设计不能识别补贴与电价是否互补、信息是否提高补贴效果、低收入保护是否缓解价格政策的负担，也没有比较先补贴后提价与先提价后补贴的差异。本研究将政策组合本身作为实验对象，而不只把政策当作模型外部输入。

本研究直接向受访者提供政策情境。例如：

> 某高能效空调价格为4000元，政府补贴800元，预计每年节省电费500元。当前经历连续30天高温，社区已有40%的家庭采用同类设备。您选择购买设备、减少用电，还是维持当前用电方式？

问卷系统改变以下属性：

- 设备价格和补贴比例；
- 电价或惩罚强度；
- 预计节电量和回本期；
- 高温持续时间；
- 信息反馈方式；
- 邻里采用比例；
- 低收入账单保护。

受访者在多个随机化情境中作出选择，由此估计：

\[
Choice_{ij}=f(Policy_j, Household_i, Policy_j×Household_i)
\]

(Choice_{ij}) 表示家庭 (i) 在情境 (j) 中的选择；(Policy_j) 是价格、补贴、信息和保障等政策属性；(Household_i) 是收入、住房、设备和基线用电等家庭属性。mixed logit、latent class model 或层级模型可以估计政策属性的边际效应、组合效应和群体差异。

直接情境选择比“心理特征—总体意愿—行为”更适合 ABM 参数化。政策变量保留现实单位，选择结果可以直接转换为采用概率、节电强度、WTP 和回本期阈值。

### 2.3 心理特征用于解释异质性

问卷仍需要测量损失厌恶、政策信任、时间偏好、舒适度底线和社会规范敏感度。这些变量不再用于生成一个抽象的总体意愿，而是用于解释相同政策下的选择差异。

例如，补贴金额相同，损失厌恶较强的家庭可能仍对惩罚更敏感；收入相同，政策信任较低的家庭可能不接受官方提供的节能收益预测；住房和设备相近，社会规范敏感度较高的家庭可能更容易受到邻里采用影响。

问卷中的关系因此变为：

```text
家庭现实约束 + 政策情境 + 心理特征交互
→ 行为路径、采用概率、节电强度和支付意愿
```

### 2.4 问卷为 ABM 提供个体联合关系

使用总体均值分别生成收入、设备、态度和 WTP，可能组合出现实中很少出现的家庭。个体问卷可以保留同一受访者的收入、住房、设备、心理特征和政策选择之间的联合关系。

Dello Russo 等（2025）比较公共汇总数据、问卷汇总分布和个体问卷初始化。个体问卷并未在所有总量指标上表现最好，但更能呈现可再生能源采用差异和社会经济分化。这正是本研究需要问卷的理由：政策组合研究不仅比较平均用电，还要判断不同家庭如何响应、谁获得收益、谁承担成本。

## 3. 问卷怎样进入 ABM

问卷不直接决定长期模拟结果，而是提供初始化和行为函数。

| 问卷内容 | Agent 参数或规则 |
|---|---|
| 家庭收入、住房、人口和设备 | 预算、设备存量、基础负荷和可改造条件 |
| 多个政策情境中的选择 | 补贴、电价、信息和保障条件下的选择概率 |
| WTP 与回本期 | 设备投资阈值 |
| 高温情境中的节电选择 | 舒适度约束和需求削减范围 |
| 政策信任和损失厌恶 | 政策响应异质性 |
| 邻里信息和社会规范题项 | 网络影响权重和扩散阈值 |

ABM 在每个时期读取天气、价格、政策和邻居状态，调用问卷估计的行为函数。行为改变账单、舒适度和设备状态，这些结果再进入下一期决策。

```text
Agent 属性
→ 当前天气、政策和邻居状态
→ 选择节电、升级设备或维持行为
→ 更新用电、账单、设备和经验
→ 下一期重新决策
```

问卷回答的是特定情境中的条件选择，ABM 计算这些选择在重复冲击、设备寿命、预算约束和社会扩散下的累积结果。

## 4. LLM 加入后提升了什么

### 4.1 传统规则和 ANN 的边界

规则模型透明，但需要研究者提前列出所有条件。当政策组合、天气、设备状态、家庭约束和历史经验同时变化时，规则数量会迅速增加。

ANN 可以拟合复杂非线性关系。Yue 等（2020）使用 BP 神经网络连接问卷输入和节能行为，说明 ANN 可以充当 Agent 内部的行为函数。但 ANN 主要学习固定的输入输出映射，难以直接处理政策文本、开放式理由、前后情境冲突和未预先编码的信息；其内部机制也不容易解释。

LLM 的价值在于增加一个受约束的情境推理层，而不是替代问卷和统计模型。

### 4.2 处理复杂政策语义

居民接收到的政策不是几个数值变量，还包括资格条件、补贴申请方式、账单保护、政策期限和执行主体。LLM 可以读取结构化数值和简短政策说明，判断政策是否适用于当前家庭。

例如，同样是20%的设备补贴，租户、现金不足家庭和已有高效设备家庭面对的实际选择不同。传统模型需要为每种情况编写分支规则；LLM 可以在预算、产权和设备约束内解释政策条件，再输出规定格式的选择。

### 4.3 表达多目标权衡和有限理性

居民选择同时受到费用、舒适度、设备寿命、风险和环保偏好影响。固定效用函数可以表达平均权衡，但很难覆盖家庭在极端高温、突发账单和政策不确定性下使用的启发式规则。

LLM 可以在问卷识别的参数范围内处理这些冲突。例如，低收入家庭可能认可设备长期节能收益，但因当期现金约束选择减少用电；有老人或儿童的家庭可能优先维持舒适度，即使电价上升也不削减空调用电。LLM 输出选择及其理由，结构模块再检查预算、设备和能耗是否满足约束。

### 4.4 使用记忆形成路径依赖

传统静态选择模型通常根据当前输入给出概率。LLM 可以读取有限的事件记忆，例如过去高温持续时间、实际节电收益、补贴申请失败、邻居使用体验和政策兑现情况。这些经历会改变下一次选择。

记忆机制使模型能够表示：

- 政策兑现提高信任；
- 节电导致明显不适后降低后续节电强度；
- 邻居设备使用成功后提高采用概率；
- 连续高温使短期节电逐渐转向设备投资。

这些路径依赖是 ABM 研究动态政策过程的重要内容。

### 4.5 利用开放式问卷信息

结构化问卷适合估计平均参数，开放式回答可以补充居民拒绝政策、担忧设备或不信任执行机构的原因。LLM 可以把开放式回答编码为有限类别或个体记忆，例如资金约束、产权障碍、信息不信任、舒适需求和申请成本。

这些信息经过人工抽样核验后，可以进入 Agent 的决策上下文，减少仅依赖量表均值造成的信息损失。

### 4.6 提高政策组合模拟的可扩展性

Policy mix 包含工具强度、组合、顺序和实施说明。完全依靠人工规则，需要为每一种组合编写行为逻辑。LLM 可以使用同一套受约束决策模板处理不同政策包，减少规则数量，并允许测试问卷未逐一展示但仍处于属性范围内的组合。

这种扩展只能用于情境探索。超出问卷属性范围或现实政策范围的组合需要标记为外推，不能与样本内情境使用相同的可信度解释。

## 5. LLM 在模型中的受约束位置

推荐使用混合架构：

\[
Decision=Structural\ Constraints+Empirical\ Choice\ Model+Bounded\ LLM\ Reasoning
\]

结构模型负责预算、设备、能耗、住房产权和政策资格；问卷估计的选择模型提供基础概率；LLM 根据政策说明、家庭状态和有限记忆进行情境修正。LLM 只能从预先定义的行为集合中选择：节电、设备投资、维持用电或延迟决策。

LLM 输出至少包括：

```text
行为选择
节电强度或采用概率
触发该选择的主要约束
使用的记忆信息
结果置信度
```

输出随后经过预算、设备可用性、能量范围和概率边界检查。不符合约束的结果由结构模型修正或退回统计基线。

## 6. 怎样证明问卷和 LLM 确实有价值

研究使用同一能源计算、天气、政策和网络环境，比较四种模型：

| 模型 | 居民行为来源 | 检验内容 |
|---|---|---|
| B0 | 公共数据和文献规则 | 无问卷基线 |
| B1 | 问卷汇总分布和统计选择模型 | 问卷总体参数的价值 |
| M1 | 个体问卷和统计选择模型 | 个体联合异质性的价值 |
| M2 | 个体问卷、统计模型和受约束 LLM | LLM 情境推理的增量价值 |

评价指标包括：

- 留出问卷情境中的选择预测；
- 收入、住房和设备群体的预测误差；
- 历史用电、设备采用和账单分布；
- 不同政策组合的相对排序；
- 低收入和高能源负担家庭的结果；
- 随机种子、Prompt、模型版本和参数变化下的稳定性。

如果 B1 优于 B0，说明问卷识别的政策响应具有价值。如果 M1 只改善群体差异而不改善总量，说明个体问卷主要服务于分配分析。如果 M2 相比 M1 提高复杂情境预测或政策排序稳定性，LLM 构成有效的技术提升；否则，LLM 只保留为开放式信息编码或解释工具。

## 7. 两项核心贡献

### 7.1 Policy mix 设计贡献

政策组合不再由“变量全部取最大值”表示，而是由具体工具、强度、顺序和保障条件构成。研究可以检验价格与补贴、信息与设备支持、惩罚与低收入保护之间的互补、替代和分配效应。政策效果同时包括用电、设备采用、财政成本和群体负担。

### 7.2 居民模型贡献

问卷直接测量家庭在随机化政策情境中的选择，心理特征解释响应差异。个体问卷保留收入、住房、设备、行为阈值和政策选择之间的联合关系。LLM 在这些经验参数和结构约束内处理政策说明、有限理性、历史记忆和社会互动。

两项贡献组成一套可检验的方法：

- 用随机化政策情境直接识别居民对政策组合的选择；
- 用心理特征解释响应差异，而不是先生成抽象意愿；
- 将个体问卷中的家庭约束、行为阈值和政策选择保留在同一 Agent 中；
- 用 LLM 增加政策语义、多目标权衡、有限记忆和开放式信息处理；
- 通过 B0、B1、M1 和 M2 的对照，分别检验问卷和 LLM 的增量价值。

这套框架把宏观 policy mix 理论转化为家庭层面的政策感知和选择，再把家庭选择汇总为动态能源和分配结果。它同时推进政策组合设计和居民 ABM 建模，而不是只在现有模型中增加一个 LLM 模块。
