# 面向 Agent 参数化的问卷设计方案

## 1. 设计目标

本问卷的目标不是仅仅测量居民的一般性低碳态度，也不是为了单独发表一篇标准的离散选择实验（Discrete Choice Experiment, DCE）论文，而是为后续的 `LLM-enhanced ABM` 提供稳定、可解释、可映射的微观参数基础。更准确地说，这是一份 `ABM parameterization-oriented survey`，其设计导向是服务于 Agent 的初始化、行为反应建模与社会传播机制建模。

围绕这一目标，问卷需要完成三项任务。

第一，识别家庭层面的异质性，为 Agent 提供初始属性。这些属性包括地区、收入水平、住房条件、设备保有量、基线用电水平、价格敏感度和低碳偏好等。

第二，识别家庭在极端高温与不同政策条件下的行为反应参数。重点不是简单测量“是否支持政策”，而是识别家庭对补贴、惩罚、回本周期、账单压力和极端气候持续时间的反应强度。

第三，识别家庭的社会影响机制。家庭能源行为并不是孤立形成的，还受到邻里、熟人、同事和线上信息的影响。因此，问卷需要测量个体的社会影响敏感性、社会接触规模、低碳规范暴露程度，以及不同社会信息如何影响其行为更新。

从建模角度看，这份问卷不是一般性的描述性问卷，而是一份带有实验属性的机制识别问卷。其最终目标是生成能够进入 Agent 决策过程的参数，而不是仅停留在统计描述层面。

## 2. 理论基础

### 2.1 DCE 的属性选择逻辑

本问卷在 D/E/F 模块中借鉴了 DCE 的设计思想，但并不将其严格限定为一份标准 DCE。其理论基础主要来自 Lancaster 的属性效用理论和 McFadden 的随机效用理论。

Lancaster 的属性理论认为，个体并不是直接从“产品本身”获得效用，而是从产品或政策所包含的属性中获得效用。对家庭能源低碳转型而言，影响行为的不是抽象的“补贴政策”或“低碳产品”概念，而是其中的具体属性，例如：

- 极端高温持续时间；
- 电费上涨幅度；
- 补贴比例；
- 惩罚强度；
- 回本周期；
- 节电收益；
- 邻里采用比例。

McFadden 的随机效用理论进一步指出，个体在若干备选方案中会选择主观效用最高的方案。因此，如果需要识别家庭在极端天气和政策冲击下的应对路径，就必须通过属性组合任务来观察家庭如何进行权衡，而不能仅通过一般态度题来推断。

这意味着，问卷中的情景任务采用属性化设计是成立的，因为家庭的选择本身就可以理解为对政策和环境属性的反应。

### 2.2 传统 ABM 的参数化需求

传统 ABM 的方法优势在于处理异质主体、局部互动、反馈机制和系统涌现。但传统 ABM 的一个经典难点是：如何为 Agent 的行为规则提供经验基础。如果没有问卷、实验、访谈或外部数据支撑，Agent 的决策机制很容易变成研究者主观设定的规则集合，从而削弱模型可信度。

因此，本问卷在本项目中的作用，不是替代 ABM，而是为 ABM 提供参数化基础。问卷负责回答以下问题：

- 不同家庭在资源禀赋上有何差异；
- 不同家庭对政策刺激的反应强度有何差异；
- 不同家庭在社会影响下的行为更新机制有何差异。

在这种意义上，问卷与 ABM 的关系不是替代关系，而是“参数识别工具”与“动态演化平台”的关系。

### 2.3 行为经济学基础

家庭能源决策并不等同于完全理性的成本最小化行为。大量行为经济学研究表明，家庭在节能、购置高能效产品和面对气候压力时，常常受到以下行为机制影响：

- 现时偏差；
- 损失厌恶；
- 心理账户；
- 默认效应；
- 框架效应；
- 社会比较；
- 有限理性下的启发式判断。

这意味着，问卷不能只问“是否愿意购买”，还必须设计能够识别以下行为特征的题项：

- 家庭更倾向通过节约用电还是升级设备来应对高电费；
- 家庭对回本周期是否高度敏感；
- 家庭对补贴和惩罚是否存在不对称反应；
- 家庭是否更容易受到邻里采用行为和低碳规范影响。

### 2.4 社会规范与扩散理论

家庭低碳行为还受到社会规范和社会扩散机制的影响。相关理论表明，至少存在以下几类重要机制：

- 描述性规范：别人都在做什么；
- 指令性规范：别人认为什么是应该做的；
- 邻里或熟人经验传播；
- 观察学习与可见性；
- 低碳行为的社会声誉效应。

因此，F 模块不能仅仅停留在“社会影响背景描述”，而必须被设计成一个能够识别社会影响参数的模块，使其输出可直接服务于网络扩散规则和行为更新机制。

## 3. 总体设计思路

本问卷不再简单按“基本信息 + 态度题 + 情景题”来理解，而是按照建模功能分层。整体上，可以分为三层。

第一层是静态属性层。该层用于识别家庭的初始异质性，直接服务于 Agent 初始化。

第二层是机制参数层。该层用于识别家庭对气候冲击、政策刺激和社会影响的行为反应强度，服务于 Agent 的行为规则赋值。

第三层是选择任务层。该层借鉴 DCE 的设计纪律，通过属性组合任务观察家庭在不同情境下的取舍路径，将其转化为可参数化的行为结果。

在这一结构下，问卷并不是为了估计一个封闭的“态度均值”，而是为了识别家庭在不同约束和激励条件下的行为机制。整体逻辑可以概括为：

- A/B/C 模块负责回答“这个家庭原本是什么样”；
- D/E 模块负责回答“在极端高温和不同政策条件下，这个家庭会如何选择”；
- F 模块负责回答“这个家庭在社会影响下如何更新行为”。

这样设计的优势在于，问卷输出可以直接进入 Agent 建模，而不只是停留在一般性的描述统计或单一回归分析。

## 4. 问卷结构设计

## A 模块：家庭基本信息

A 模块的主要作用是识别家庭的基本社会经济属性，为 Agent 提供初始异质性基础。建议保留并强化以下信息：

- 所在地区或城市；
- 家庭人口数；
- 收入水平；
- 教育程度；
- 住房面积；
- 住房类型；
- 是否自有住房。

这些题项并不是简单用于人口学控制，而是直接决定 Agent 的资源约束、消费能力和群体分层位置。

## B 模块：家庭能源使用基线

B 模块用于建立家庭在没有政策干预时的能源行为基线。建议保留当前 `v12` 中已有的基线信息，包括：

- 平时月用电量；
- 账单月份；
- 空调数量；
- 冰箱数量；
- 热水器数量或类型；
- 是否有电动车；
- 是否有分布式光伏或储能。

这一模块的作用是将家庭偏好与真实设备结构、用电基线联系起来，使后续极端高温情景中的用电冲击具有现实锚点。

## C 模块：低碳路径偏好与基线倾向

C 模块用于识别家庭在没有强情景刺激前的低碳转型倾向。建议保留并明确以下内容：

- 更倾向通过节约用电还是升级设备来应对高电费；
- 是否愿意为高能效或低碳产品支付额外成本；
- 可接受的回本周期；
- 环保偏好与生活舒适偏好的相对权重。

这一模块的作用是区分“本来就愿意转型”的家庭和“需要外部刺激才可能转型”的家庭。

## C1 模块：政策响应程度

C1 模块用于识别家庭对不同类型政策工具的总体响应倾向。与 D/E 模块中的情景化选择不同，C1 不强调某一个具体极端天气场景，而是测量家庭在一般条件下对政策工具的稳定反应方向。

建议围绕以下几类政策工具设置量表题：

- 购置补贴或价格优惠；
- 阶梯电价、惩罚性收费等约束工具；
- 账单反馈、节电收益和回本期信息；
- 安装便利、申请流程简化、接入支持等基础设施或实施便利性工具；
- 节能建议、同类家庭比较、极端天气风险提示等信息型工具。

这一模块的作用在于，将“情景中的即时选择”与“对政策工具的长期响应倾向”区分开来。前者主要由 D/E 模块识别，后者则由 C1 模块补充，从而使 Agent 既有情景反应参数，也有较稳定的政策敏感度参数。

## D/E 模块：DCE-inspired choice tasks

D/E 模块是整份问卷中最核心的实验部分。其目标不是设计一套纯标准 DCE，而是借鉴 DCE 的属性化思路，构造能够为 Agent 提供行为反应参数的情景任务。因此，这两个模块更适合被定义为 `DCE-inspired choice tasks`。

### D 模块：短期极端高温情景

D 模块聚焦连续 7 天左右的极端高温情景，主要识别家庭在短期高温冲击下的即时行为反应。

### E 模块：长期极端高温情景

E 模块聚焦连续 30 天左右的极端高温情景，主要识别家庭在持续高压条件下是否发生路径切换，例如从节约用电转向设备升级，或者从“不行动”转向适应性投资。

### D/E 模块的设计原则

每个 choice task 不应只是单纯展示四种政策整包情景，而应以属性组合方式呈现。建议保留当前 `v12` 中关于补贴、惩罚、账单反馈和回本测算的基本结构，但在分析设计上将其理解为一组属性：

- 极端高温持续时间；
- 电费上升压力；
- 补贴水平；
- 惩罚强度；
- 回本周期；
- 预计节电收益；
- 可能的社会采用提示。

在每个任务中，建议保留以下结果变量：

- 主路径选择：节电、设备升级、两者并行偏节电、两者并行偏升级、不采取行动；
- 购买意愿强度；
- 节电意愿强度。

这种设计能够让 D/E 模块不仅回答“喜欢哪个政策情景”，还能够识别家庭对不同属性的边际反应，从而更适合用于 Agent 参数化。

## F 模块：社会影响参数识别模块

在当前 `v12` 中，F 模块已被拆分为三个部分，这一方向是合理的。后续应将其进一步明确为一个“社会影响参数识别模块”。

### F1：个人社会影响敏感性

用于测量个体在家庭用电和电器购买决策上是否容易受他人影响。该部分保留量表化设计是合理的，因为其主要目标是识别稳定的个体差异。

### F2：社会接触规模

用于测量过去一个月中会影响其家庭用电方式或电器购买决策的人数规模。这一指标可以用于近似表示个体在社会网络中的接触半径或暴露规模。

### F3：低碳规范暴露程度

用于测量在其可能影响自己的人群中，支持节电、购买节能电器或采用低碳产品的人所占比例。该部分保留当前 `v12` 的比例式设计是合理的，因为它能直接生成用于仿真的规范暴露参数。

### F4：社会影响任务扩展

虽然当前 `v12` 尚未实现 F4，但后续建议在 F 模块中预留一个社会影响任务扩展部分，用于估计“什么样的社会信息最能影响家庭行为”。该部分可以围绕以下属性设计小规模情景任务：

- 信息来源：家人、邻居、同事、线上平台；
- 信息类型：省钱经验、舒适体验、环保理由、避免停电；
- 规范方向：别人都这么做、别人认为应该这么做；
- 可见性：听说、亲眼看到；
- 采用比例：少数人、一半、大多数。

这一扩展的意义在于，使 F 模块不仅能识别“是否容易受影响”，还能识别“受什么影响、受谁影响、在什么条件下受影响”。

## 5. 问卷如何参数化为 Agent

本问卷之所以服务于 Agent 建模，关键在于每个模块都能够稳定映射为 Agent 参数。建议将参数映射划分为三层。

### 5.1 静态初始化参数

这一层主要来自 A/B/C 模块，用于初始化 Agent 的资源禀赋和基线偏好。包括但不限于：

- `location`
- `income_level`
- `house_area`
- `household_size`
- `education`
- `baseline_kwh`
- `billing_month`
- `ac_count`
- `fridge_count`
- `heater_count`
- `has_ev`
- `has_pv`
- `lowcarbon_path_preference`
- `baseline_adoption_intention`

这些参数构成 Agent 的起始状态，使模拟中的家庭不再是“平均家庭”，而是具有明确异质性的个体。

### 5.2 行为反应参数

这一层主要来自 C1 与 D/E 模块，用于刻画家庭在不同政策和气候条件下如何调整行为。包括：

- `heat_duration_sensitivity`
- `price_shock_sensitivity`
- `subsidy_sensitivity`：家庭对补贴、价格优惠等激励型工具的响应程度，即补贴出现或增强时，其购买或升级行为被推动的幅度。
- `penalty_sensitivity`：家庭对阶梯电价、惩罚性收费等约束型工具的响应程度，即成本压力上升时，其减少用电或改变路径的幅度。
- `policy_feedback_sensitivity`：家庭对账单反馈、节电收益展示和回本期信息的响应程度，即信息透明化后其更可能采取行动的程度。
- `infrastructure_support_sensitivity`：家庭对安装便利、申请流程简化、设备接入条件改善等支持性政策的响应程度。
- `information_guidance_sensitivity`：家庭对节能建议、同类家庭比较、风险提示等信息型政策的响应程度。
- `payback_tolerance`：家庭对投资回收期的容忍程度，即在购买节能/低碳产品时，最长可接受多长时间收回成本。
- `saving_intensity`：家庭在特定气候和政策情境下主动压缩用电的强度，可理解为“愿意节多少、会节到什么程度”。
- `adoption_probability`：家庭在给定情境下采纳节能/低碳产品的概率倾向，用于把购买意愿映射为模拟中的采用可能性。
- `inaction_threshold`：家庭维持“不行动”状态所需的最低触发门槛，门槛越高，说明需要更强的价格、气候或社会刺激才会改变行为。
- `action_path_preference`：家庭在多种应对路径之间的相对偏好，即更倾向优先节电、优先升级设备、两者并行，还是暂不行动。

其中需要特别区分两类支付意愿：

- `wtp_lowcarbon_extra`：低碳产品额外支付意愿，即家庭愿意为高能效或低碳产品相对普通产品支付的额外成本；
- `reliability_wtp`：保供/可靠性支付意愿，即极端天气供电紧张时，为避免限电或维持舒适性而愿意额外支付的金额。

两者在理论和建模上承担不同角色，不能混用。

### 5.3 社会传播参数

这一层主要来自 F 模块，用于刻画家庭在社会互动中的传播和更新机制。包括：

- `social_susceptibility`
- `network_size`
- `norm_exposure`
- `network_exposure`
- `neighbor_influence_weight`
- `family_influence_weight`
- `online_influence_weight`
- `descriptive_norm_weight`：个体对“别人实际上都在怎么做”这类描述性规范的敏感权重，例如看到大多数邻居已换用高能效设备后，其自身行为被带动的程度。
- `injunctive_norm_weight`：个体对“别人认为应该怎么做”这类指令性规范的敏感权重，例如来自家人、社区或同事的道德期待和规劝对其决策的影响程度。
- `message_type_weight`：个体对不同信息内容的响应权重，例如更容易被“省钱”说服、被“舒适性提升”说服，还是被“环保责任”或“避免停电风险”说服。

当前 `v12` 至少已经能够较稳定地支持以下三项：

- 个人社会影响敏感性；
- 社会接触规模；
- 低碳规范暴露程度。

若后续加入 F4，则可以进一步支持更精细的社会传播参数。

## 6. 为什么这样设计问卷是成立的

首先，这样的问卷设计具有明确的理论基础。它并不是随意拼接态度题和情景题，而是同时建立在属性效用理论、随机效用理论、传统 ABM 参数化逻辑、行为经济学以及社会规范扩散理论之上。因此，问卷中的每一类题项都有其方法论依据。

其次，这样的问卷设计服务于一个明确的建模任务。其目的不是泛泛地测量居民态度，而是识别家庭在极端高温和政策组合条件下的行为变化机制，并将其转化为 Agent 可用的参数。因此，问卷设计从一开始就是“为建模服务”，而不是“问卷做完以后再看看能不能用于建模”。

再次，这种设计同时捕捉“状态”和“机制”。A/B/C 模块主要测量家庭当前状态和基线特征，D/E 模块测量家庭在具体冲击条件下的行为变化，F 模块测量行为更新和社会扩散机制。这样，问卷不仅描述家庭是什么样，还能解释家庭为什么会在不同条件下做出不同反应。

最后，这种设计保留了现实行为的开放性。纯标准 DCE 往往会把个体压缩进预设选择集合中，而本问卷通过“路径选择 + 意愿强度 + 社会影响参数”的组合，尽量保留家庭在真实世界中可能采取的多种应对方式，包括节电、设备升级、两者并行以及不行动。这使问卷更适合为 ABM 提供机制基础。

## 7. 为什么这样的问卷能生成有效的 Agent

首先，这样的问卷让 Agent 的关键属性不再完全凭空设定。传统 ABM 的主要弱点之一在于参数和行为规则容易依赖研究者主观判断，而本问卷通过系统采集家庭的基线特征、行为反应和社会影响机制，使 Agent 的关键参数有了可追溯的数据来源。

其次，这样的问卷提供的是“行为参数”，而不仅仅是抽象态度。有效的 Agent 不需要一个笼统的“支持低碳程度”，而需要知道：补贴提高多少会改变行为，回本期超过多久会降低采用概率，极端高温持续多久会促使家庭切换路径，邻里采用比例达到什么程度会触发模仿反应。D/E/F 模块正是在识别这些更接近行为规则的参数。

第三，这样的问卷能够支持异质性建模。不同收入水平、不同设备保有量、不同价格敏感度和不同社会暴露程度的家庭，对同一政策工具和同一气候冲击的反应并不相同。问卷通过显式采集这些差异，使 Agent 可以表现为一个有分布的群体，而不是一组同质个体。

第四，这样的问卷能够支持内部验证。如果样本规模足够，例如收集约 1000 份问卷，则完全可以采用分样本方式进行内部验证，例如前一部分样本用于参数化，后一部分样本用于样本外检验。这种做法不能替代外部效度检验，但能够检验模型是否仅仅拟合了少量训练样本，从而提高 Agent 构造的内部可信度。

第五，这样的问卷与传统 ABM 兼容。当前项目的算法本质上仍然是传统 ABM，只是在部分复杂行为节点上引入了 LLM 增强。因此，这份问卷生成的参数既可以服务于规则型 ABM，也可以服务于参数化 ABM 和 LLM-enhanced ABM。这意味着它不仅能生成 Agent，还能支持方法比较。

## 8. 需要注意的边界

第一，问卷不能自动带来强外部效度。问卷可以很好地服务于参数化、异质性识别和内部验证，但不能单独证明模型一定能准确预测现实未来行为。更强意义上的外部合理性仍需结合区域用电统计、高温天负荷数据、设备采用率数据和真实政策事实结果来进行校验。

第二，问卷不应在产品维度上过度扩张。如果同时纳入过多低碳产品，choice task 会迅速变得复杂，受访者的认知负担会显著上升，参数稳定性也会下降。因此，更合理的做法是优先保留最有代表性的 2 至 3 类产品，例如高能效空调、热泵热水器和分布式光伏。

第三，任务数量需要控制。D/E/F 的设计如果过长，会导致受访者疲劳并降低题项质量。较稳妥的做法是，在 D 和 E 中分别控制 choice task 数量，并将 F4 设计为小规模扩展模块，而不是大规模平行实验。

第四，问卷结果不能直接等同于现实行为本身。问卷识别的是偏好、倾向和反应参数，而不是现实中的直接行为观测。因此，这些参数进入 Agent 后，仍需通过理论约束、模型结构和外部合理性检验来共同支撑结果解释。

总之，这份问卷之所以成立，不是因为它模仿了某一种单独的方法，而是因为它把 DCE 的设计纪律、ABM 的参数化需求、行为经济学的机制识别和社会扩散理论结合起来，形成了一套能够直接服务于 Agent 建模的研究工具。
