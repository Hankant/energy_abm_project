# 电子问卷 v12 逐题操作性修订指南

## 1. 使用说明

本指南用于把 `survey/electronic_lowcarbon_survey_v12.html` 从“个性化情景计算器原型”逐步改造成可支持家庭异质性识别、政策组合实验和经验型ABM参数化的调查工具。

本指南不直接修改v12，也不把下列建议题项宣称为已经验证的成熟量表。正式进入预测试前，每一道题仍需维护来源、原文、翻译、修改理由、构念、量尺、编码、ABM用途和调查轮次。

### 修订标记

- **P0：必须修改**。不修改会导致政策效应、Agent状态或行为机制无法识别。
- **P1：重要修改**。不修改会明显降低效度、解释力或可复现性。
- **P2：优化修改**。主要改善答题质量、数据清洗或用户体验。
- **保留**：结构可以保留，但仍需核验措辞和编码。
- **改写**：保留测量目标，替换题干或选项。
- **拆分**：原题混合多个概念，应拆成多题或矩阵。
- **删除/替代**：原题不能支持目标构念，应由新模块替代。

## 2. 建议的总体问卷结构

| 新模块 | 目标 | 建议常规题量 | 主要ABM用途 |
|---|---|---:|---|
| A. 筛选、同意与家庭能源决策角色 | 确认样本资格和回答者知情程度 | 3–4 | 样本筛选、决策者权重 |
| B. 家庭、住房、设备与能源基线 | 确定家庭资源和行为可行集 | 12–15 | Agent初始化、约束、预算、设备存量 |
| C. 既有家庭能源行为 | 识别HAB、QTB、EIB、IFB基线 | 10–14个行为条目 | 基线行为状态、家庭类型 |
| D. 心理与社会机制 | 测量态度、规范、控制感、道德规范和初始意愿 | 12–16 | 潜变量、决策函数、类型识别 |
| E. 制度、公平与政策经验 | 测量一般政策评价背景 | 6–8 | 初始政策信念、评价异质性 |
| F. 随机政策组合情景 | 识别政策属性和组合响应 | 每人4–6个随机任务 | 外生处理、条件选择概率 |
| G. 社会互动与动态更新 | 识别社会暴露、信息影响和可能的更新机制 | 5–8 | 网络暴露、规范权重、更新参数 |
| H. 质量控制与结束语 | 记录质量、开放意见和调查元数据 | 2–3 | 样本质控、机制补充 |

目标为约45–55个常规可见问题，另加每人4–6个随机政策情景。正式预计时长应通过预测试实测，初始控制目标可设为18–25分钟。

## 3. 逐题修订

## 3.1 知情同意

### 现有题：同意复选框

**处理：改写，P1。**

现有文本只说明匿名和学术用途，缺少研究机构/负责人、预计时长、数据保存、潜在风险、联系方式和退出后数据处理方式。

建议至少补充：

1. 研究目的：研究家庭能源决策与政策评价，而不是测试个人知识；
2. 预计时长；
3. 收集的数据类型及是否收集IP、定位或设备信息；
4. 数据保存期限、访问范围和匿名化方式；
5. 参与自愿、可退出、跳题规则和潜在不适；
6. 研究团队与伦理审批/联系方式；
7. 情景中的价格和政策为研究设定，不代表政府已作决定。

建议选项：

- 我已年满18岁，已阅读说明并自愿参加；
- 我不同意参加（结束问卷）。

不要仅依赖HTML的 `required` 属性阻止退出。

## 3.2 A模块：基本信息与决策角色

### 新增 A0：家庭能源决策角色

**处理：新增，P0。**

建议题干：

> 在您家，您对日常用电、电费支付或主要家电购买的了解和参与程度如何？

建议选项：

1. 我是主要决定者；
2. 我与其他家庭成员共同决定；
3. 我会参与讨论，但通常不是决定者；
4. 我很少参与，但了解家庭大致情况；
5. 我既不参与，也不了解相关情况。

操作规则：选择5者原则上结束问卷；选择4者可继续，但对精确账单、设备和购买决策题增加“不知道”选项，并记录较低的决策信息权重。

ABM用途：`decision_role`、回答可靠性分层，不直接作为环保倾向。

### 现有“年龄”→ A1

**处理：保留并改进，P2。**

当前使用18–100岁数值输入基本可行。建议增加：

- 不愿透露；
- 后台按预注册规则分组，不在问卷端预先粗分；
- 检查异常值，但不要自动把高龄者排除。

ABM用途：人口属性、舒适需求和技术采用异质性的候选变量；不能预设年龄必然降低低碳倾向。

### 现有“性别”→ A2

**处理：基本保留，P2。**

建议选项保持“男、女、其他/自我描述、不愿透露”。如果研究不分析性别机制，也可仅作为描述变量，避免强行进入行为方程。

### 现有“最高受教育程度”→ A3

**处理：保留，P2。**

建议增加“不愿透露”。教育程度是描述变量，不直接等同于政策理解或环境知识；政策理解需要单独测量或设置理解检查。

### 现有“所在城市/地区”→ A4

**处理：改写，P1。**

自由文本容易出现同城不同写法，无法可靠连接地区电价、气候和政策数据。

建议设计：

- 省/自治区/直辖市：下拉；
- 地级市：联动下拉；
- 区县：可选；
- 城乡属性：城区、县城/镇区、农村地区、不确定。

如果研究最终限定同一地区，则直接记录抽样点代码，不必重复询问过细地址。不要收集可识别的详细住址。

ABM用途：外部环境、气候、电价和抽样分层，不应作为自由文本直接进入模型。

### 现有“家庭常住人口数”→ A5

**处理：拆分，P1。**

建议至少分为：

- 家庭常住总人数；
- 0–14岁人数；
- 65岁及以上人数；
- 是否有因健康原因对高温特别敏感的成员：有、没有、不确定/不愿回答。

必须设置逻辑校验：分项人数之和不能超过总人数。

ABM用途：能源服务需求、极端高温暴露和脆弱性，而非单一 `hhsize`。

### 现有“家庭月总收入”→ A6

**处理：改写，P1。**

当前题目没有说明税前/税后及是否为通常月份。建议题干：

> 过去12个月，您家庭平均每月可支配收入大约是多少？请包括共同生活家庭成员的工资、经营、养老金和转移性收入；如不清楚可选择“不知道”。

建议选项应结合目标地区分布在预测试前校准，并同时保留：

- 不知道；
- 不愿透露。

“不知道”和“不愿透露”不能合并。建议派生等价化收入或人均收入，但保留原始家庭收入区间。

ABM用途：预算约束和分配效应分组，不直接代表支付意愿。

## 3.3 B模块：住房、设备和能源基线

### 新增 B0：住房产权

**处理：新增，P0。**

建议选项：

1. 自有住房且已还清贷款；
2. 自有住房且正在还贷；
3. 租赁整套住房；
4. 租赁单间/合租；
5. 单位或保障性住房；
6. 与亲友共同居住；
7. 其他；
8. 不愿透露。

ABM用途：确定住房改造、光伏和固定设备投资的可行性。

### 新增 B0a：住房类型与面积

**处理：新增，P0。**

建议分别询问：

- 住房类型：多层住宅、高层住宅、联排/独栋、自建房、其他；
- 建筑面积区间；
- 建筑大致年代；
- 是否可自主安装或更换固定能源设备：可以、需业主/物业同意、不可以、不确定。

这些题用于确定行为可行集，不能只当控制变量。

### 现有 B1：“过去1个月用电量”

**处理：改写，P0。**

现有问题强制输入1–5000 kWh，不允许不知道，可能迫使受访者猜测。

建议题干：

> 请查看最近一期家庭电费账单。该账单覆盖多少天、用电量是多少？

建议回答结构：

- 我可以填写准确数值：____ kWh；账单天数：____天；
- 我只知道大致范围：0–100、101–200、201–300、301–500、501–800、801–1200、1200以上；
- 我没有查看账单；
- 家庭电费由他人支付，我不知道；
- 住房电费包含在租金或单位费用中；
- 不愿回答。

如果不能实现双模式输入，至少增加“不知道/无法获得”。精确值和区间值必须用不同变量保存。

### 新增 B1a：实际电费

**处理：新增，P1。**

建议询问同期电费金额及是否包含公共分摊、充电或其他费用，用于交叉核查kWh和当地电价，而不是用研究者公式完全替代真实账单。

### 现有 B2：“账单对应月份”

**处理：保留并改写，P1。**

应与B1的账单日期或账单天数联动。建议让受访者选择账单起止月，或记录最近一期账单结束月份。若无法查看账单，允许“不确定”。

### 现有三项“电器数量”

**处理：拆分并取消默认值，P0。**

当前空调、冰箱和热水器默认均为1台，容易把未修改的默认值误当真实回答。所有设备题默认应为空。

对每类关键设备建议采用条件矩阵：

| 内容 | 建议选项 |
|---|---|
| 是否拥有 | 有、没有、不确定 |
| 数量 | 0、1、2、3、4、5台及以上 |
| 主要设备类型 | 按产品实际分类设置 |
| 使用年限 | 不足1年、1–3年、4–7年、8–10年、10年以上、不知道 |
| 能效等级 | 1级、2级、3级及以下、不知道/未标识 |
| 是否计划两年内更换 | 是、否、不确定 |

产品情景必须依据设备拥有、使用年限和住房条件进行路由。例如没有安装条件的家庭不能进入分布式光伏采用任务。

### 新增 B3：日常能源支付与预算约束

建议增加：

- 家庭电费通常由谁支付；
- 过去一年是否曾因电费压力减少必要用电；
- 面对一次性节能投资，更接近“可以直接支付、需要分期、只有较高补贴才可能、目前无法承担、不确定”中的哪一种。

注意：该题测量预算/融资约束，不应被解释为环境态度。

## 3.4 现有C模块：低碳路径偏好

### 现有 C1：“更倾向于哪种方式”

**处理：删除并由实际行为模块替代，P0。**

问题包括：

- 同时给出“降低成本”和“促进环保”两个动机；
- 强迫受访者在节约和购买之间选择；
- 没有“不行动、不适用、不确定”；
- 测量抽象偏好而非既有行为；
- 不能区分HAB与QTB，也没有IFB。

如果需要保留基线路径倾向，可在实际行为模块后设置：

> 如果未来一年需要降低家庭能源费用，您最可能首先采取哪一种行动？

建议选项：

1. 调整日常使用习惯；
2. 在极端情况下接受一定舒适度降低；
3. 更换或购买高能效设备；
4. 改造住房或安装分布式能源设备；
5. 向亲友或专业人员获取建议后再决定；
6. 暂不采取行动；
7. 目前无法判断。

该题只能作为“首选路径”，不能代替四行为域测量。

### 现有 C2：“相比单纯减少用电，我更愿意……提升家庭生活质量”

**处理：删除/拆分，P0。**

该题同时比较节电与购买、包含生活质量改善，并带有对高效产品的正向暗示。它无法判断受访者同意的是购买倾向，还是生活质量偏好。

若研究确实需要比较舒适偏好与投资偏好，应拆为独立、行为明确的题：

- 当天气炎热时，即使电费增加，我也不愿明显降低空调使用带来的舒适度；
- 如果高能效设备能降低长期电费，我愿意承担较高的一次性购买成本。

两题仍属于候选指标，不能未经验证直接命名为 `quality_preference` 或 `investment_preference`。

## 3.5 新增C模块：既有实际行为矩阵

**处理：新增，P0。**

统一时间窗口建议采用“过去12个月”；高频习惯可补充“通常频率”。每个行为必须允许“不适用”。

建议回答列：

1. 从未；
2. 很少；
3. 有时；
4. 经常；
5. 几乎总是；
6. 本家庭不适用；
7. 因客观条件无法实施。

候选行为域和题项示例：

| 行为域 | 候选题项示例 | 说明 |
|---|---|---|
| HAB | 离开房间时关闭不需要的照明或电器 | 需规定过去12个月/通常频率 |
| HAB | 不使用设备时关闭电源而非长期待机 | 检查设备适用性 |
| HAB | 根据实际需要调整空调运行时间 | 避免把必要高温防护描述为浪费 |
| QTB | 在不影响健康安全的情况下，适当提高夏季空调设定温度 | 明确健康安全边界 |
| QTB | 为节约电费，在部分时段减少非必要的高耗能使用 | 与能源贫困导致的被迫削减区分 |
| EIB | 购买家电时比较过能效等级和长期运行成本 | 可用于投资准备状态 |
| EIB | 过去12个月购买或更换过高能效家电 | 同时问设备和发生时间 |
| EIB | 对住房保温、光伏或其他固定设施进行过投资 | 按产权和安装条件路由 |
| IFB | 与亲友分享过节电方法或设备使用经验 | 测实际互动而非态度 |
| IFB | 向亲友推荐过高能效产品或低碳方案 | 与商业推广区分 |

正式题项应从GEB-50、OECD EPIC、RECS、UK DECC行为清单以及Yue等行为示例中筛选，并逐题记录是采用、适配还是自编。

## 3.6 新增D模块：心理机制

**处理：新增，P0。**

心理题必须围绕明确行为和时间窗口。建议先选择一个共同目标行为，例如：

> “未来12个月，在家庭条件允许的情况下采取至少一项能够降低家庭用电量或提高用电效率的行动。”

然后用统一的5点或7点量尺测量：

| 构念 | 建议题数 | 候选测量内容 | ABM用途 |
|---|---:|---|---|
| 态度 | 3 | 有益/无益、值得/不值得、总体好/坏 | 行为效用或倾向 |
| 命令性规范 | 2–3 | 对我重要的人是否认为我应该采取行动 | 社会认可压力 |
| 描述性规范 | 2 | 与我情况相似的人实际是否采取行动 | 观察到的规范 |
| 知觉行为控制 | 3 | 是否有能力、资源和决定权采取行动 | 可执行能力 |
| 个人道德规范 | 2–3 | 是否感到个人责任或义务 | 内在规范 |
| 初始意愿 | 2–3 | 未来12个月打算、计划或愿意采取行动 | 基线意愿状态 |

操作要求：

- 不直接复制Liu等（2020）未公开的中文版本；
- 根据公开英文题项翻译或改编时明确标注；
- 预测试后检验构念结构；
- 不在HTML中预先把题目均值直接写成最终Agent参数；
- 如果不同目标行为的机制显著不同，应分别为HAB和EIB设置精简构念，而不是使用一个过宽的“低碳行为”。

## 3.7 新增E模块：一般制度、公平与政策经验

**处理：新增，P0。**

这些变量原则上全卷测一次，不必在每个情景重复：

1. 对负责居民能源政策的政府部门能否兑现承诺的一般信任；
2. 过去是否接触或申请过家电补贴、峰谷电价、阶梯电价或节能改造项目；
3. 过去政策经验总体是否顺利；
4. 政策制定前是否应向居民说明依据并听取意见（程序公平观）；
5. 能源政策是否应优先保护低收入、租户或高温健康风险家庭（分配公平偏好）；
6. 对价格型工具和补贴型工具的一般接受程度。

政策经验应增加“未听说过/听说但未参与/申请过但未获得/成功获得”等选项，不能只问“是否参与”。

## 3.8 现有D/E模块：7天和30天极热政策情景

### 现有产品选择器

**处理：删除受访者自由选择，改为后台随机和条件路由，P0。**

当前由受访者选择空调、冰箱、热泵热水器或光伏，导致产品选择与原有偏好、住房条件和收入混杂，不能把不同产品的响应直接比较为实验效应。

建议：

1. 根据B模块判断产品是否适用；
2. 在适用产品中随机分配一种，或采用预先平衡的问卷版本；
3. 保存 `product_assignment_probability`、`product_version` 和随机种子/任务表；
4. 不适用固定设施投资的家庭转入通用高能效家电任务。

### 现有“7天先、30天后”

**处理：随机化，P0。**

持续时间可以保留为政策/气候属性，但不能让所有受访者固定先答7天再答30天。可采用：

- 每位受访者只看到一种持续时间；或
- 每人看到多个任务，但任务顺序随机；或
- 采用平衡区组，使7天和30天在不同版本中对调。

如果比较同一受访者的路径变化，必须在分析中处理重复测量和顺序效应。

### 现有四情景固定顺序

**处理：改成随机区组任务，P0。**

不再固定呈现“无政策→激励→惩罚→组合”。建议预先生成实验设计表，每名受访者随机获得4–6个任务。每条数据至少保存：

- respondent_id；
- survey_wave；
- questionnaire_version；
- task_id；
- block_id；
- presentation_order；
- product_assignment；
- 每个政策属性的真实水平；
- 情景计算版本；
- 作答时间。

### 建议的政策属性表

下面只作为实验设计占位框架，具体数值必须根据目标地区现实政策和统计设计确定：

| 属性 | 候选水平类型 | 理论作用 |
|---|---|---|
| 购置支持 | 无、低、高，或固定金额/比例 | 激励工具强度 |
| 高用电价格信号 | 无、较弱、较强 | 规制/经济约束强度 |
| 信息反馈 | 无、月度账单提示、及时反馈 | 信息工具 |
| 低收入或特殊家庭保护 | 无、部分保护、明确豁免/补偿 | 分配公平与目标群体设计 |
| 政策期限 | 临时、一定期限、长期稳定 | 可信度和投资预期 |
| 工具协调说明 | 分散实施、统一说明与办理 | 被感知的协调性/一致性 |

属性数和水平不能凭直觉直接全因子组合。应先明确主要效应和交互效应，再生成高效设计，并检查水平平衡、组合合理性和现实可行性。

### 现有个性化账单计算

**处理：保留技术框架，重做数值依据，P0。**

当前极热增幅、产品价格、节电率、补贴和回本期产生较强精确感，但未在问卷中标出证据来源。操作要求：

1. 每个数值记录地区、年份、政策文件或产品统计来源；
2. 区分现实已有阶梯电价与实验新增惩罚；
3. 对不确定估算优先呈现合理区间，而不是精确到小数点后两位；
4. 在认知访谈中测试受访者是否理解“估算”而非真实预测；
5. 保存公式版本；
6. 对极热用电增幅、节电率和价格进行敏感性分析；
7. 正式调查前冻结情景计算版本，调查中不得随意修改。

### 现有每情景第1题：家庭更可能采取哪种方式

**处理：拆分，P0。**

当前强制单选把可能同时发生的行为压成一个路径。建议分成两步。

第一步，多选行为响应：

> 在上述政策和极热情境下，未来【明确时间窗口】您家庭可能采取哪些行动？可多选。

- 调整日常用电习惯（HAB）；
- 在不影响健康安全的情况下减少部分舒适性用电（QTB）；
- 购买或更换高能效设备（EIB）；
- 改造住房或安装固定低碳设施（EIB，按条件显示）；
- 咨询、讨论或向他人分享相关信息（IFB）；
- 维持目前做法；
- 因客观条件无法采取上述行动；
- 不确定。

第二步，首要行动：仅向多选两个及以上行动者显示，让其选“最可能首先做的一项”。

这样既保留多行为并存，又可为ABM生成动作优先级。

### 现有每情景第2题：购买或更换产品意愿

**处理：改写，P0。**

必须指定产品、时间和可行条件：

> 如果上述政策在您所在地区实施，且该产品适用于您的住房，您家庭在未来12个月购买或更换【随机分配产品】的可能性有多大？

建议使用概率型选项以便进入选择模型：

- 0%，完全不可能；
- 1%–20%；
- 21%–40%；
- 41%–60%；
- 61%–80%；
- 81%–99%；
- 100%，肯定会；
- 无法判断；
- 不适用/没有决定权。

也可保留5点可能性量尺，但不能把“意愿强”直接解释为现实购买概率，必须通过留出情景或第二轮数据校准。

### 现有每情景第3题：减少用电意愿

**处理：拆分，P0。**

“减少用电”可能代表减少浪费、牺牲舒适度或被迫能源贫困。建议至少拆为：

1. 调整非必要用电和日常习惯的可能性；
2. 在不影响健康安全的情况下减少舒适性用电的可能性；
3. 预计总用电量相对目前会：明显增加、略有增加、基本不变、略有减少、明显减少、无法判断。

第一题对应HAB，第二题对应QTB，第三题作为情景结果和宏观用电变化的校准指标。

### 每个情景必须新增的政策结果题

**处理：新增，P0。**

建议所有情景使用相同的5点或7点量尺，至少包括：

| 结果 | 建议题干核心 | 变量角色 |
|---|---|---|
| 总体支持 | 总体而言，我支持实施上述政策方案 | 主要政策结果 |
| 有效性感知 | 该方案能够有效降低家庭高峰用电或促进效率投资 | 中介评价 |
| 分配公平 | 该方案对不同收入和住房条件的家庭总体公平 | 中介评价 |
| 家庭负担 | 该方案会给我家带来难以承受的经济或生活负担 | 中介评价，建议反向方向明确编码 |
| 可信度 | 我相信该方案会按说明持续、稳定地执行 | 中介评价/状态 |
| 参与或遵从 | 如果实施，我家会按要求参与或调整行为 | 行为前置结果 |
| 预计行为变化 | 采用前述HAB/QTB/EIB/IFB及用电变化题 | 行为结果 |

如果研究要测policy mix的consistency、coherence和comprehensiveness，应增加相应的居民语言题项，但必须标为本研究开发，并在认知访谈中检验是否能被普通居民区分。不要在每个情景重复过多近义题；可采用精简情景题加全卷一次的详细构念验证题。

## 3.9 现有F模块：社会影响

### 现有 F1三题

**处理：拆分构念，P0。**

当前三题混合从众、改变想法和参考经验，不能未经验证直接平均成 `socialInfluenceSusceptibility`。

建议至少区分：

1. **描述性规范**：与我情况相似的人中，实际采取节电/高效设备行动的人很多；
2. **命令性规范**：对我重要的人认为我应该采取这些行动；
3. **信息性影响**：在决定是否购买设备前，我会参考熟人的实际使用经验；
4. **行为更新倾向**：当可信的人提供与我原先判断不同的信息时，我会重新考虑决定。

每个构念原则上需要多题测量；若受访者负担不允许，应优先保留理论上直接进入模型的构念，并承认单题测量限制。

### 现有 F2：可能影响自己的总人数

**处理：改写，P1。**

“能想到多少位会影响自己的人”可能测到主观影响判断，而不是实际接触网络。建议题干：

> 过去1个月，您与多少位不同的人实际讨论过家庭电费、节电方式、空调使用或家电购买？

建议选项：0、1、2、3–5、6–10、11–20、20人以上、不记得。

可追加关系类型多选：共同居住家人、其他亲属、邻居、朋友、同事、线上认识的人、销售/维修/专业人员。

不要未经依据把“10人以上”固定赋值为12。区间中点、顶端区间假设和标准化方式应在分析计划中预先规定并进行敏感性分析。

### 现有 F3：支持低碳者的比例

**处理：改写并增加跳转，P0。**

“支持节电”是命令性态度，“实际采取行为”是描述性规范，两者不能混合。

如果F2=0，应跳过本题并编码为“无可观察网络”，而不是要求回答比例。

建议拆为：

- 在这些人中，您认为实际经常节电或使用高能效产品的人大约有多少？
- 在这些人中，明确赞同您采取节电或高效设备行动的人大约有多少？

选项可使用：没有、少数、约一半、多数、几乎全部、不知道。

“不知道”必须保留为缺失或不确定性状态，不能在代码中自动替换为0.5。

### 新增社会信息小情景

**处理：可选新增，P1。**

如果ABM要模拟社会扩散，可随机显示一条简短信息，例如邻居采用比例、信息来源和使用结果，再询问购买/节电概率是否变化。示例属性：

- 采用比例：20%、50%、80%；
- 来源：邻居、亲友、官方平台、销售人员；
- 结果：节省较少、达到预期、超过预期；
- 是否与受访者住房条件相似。

该任务比直接询问“你多容易受影响”更接近更新规则，但必须控制任务数量，并与政策情景的顺序随机化。

## 3.10 H模块：质量控制与结束题

### 新增注意力/理解检验

**处理：新增，P1。**

建议优先采用与情景理解有关的问题，而不是无意义的“请选择某个数字”：

- 上述方案是否包含购置补贴？
- 上述方案是否对特定家庭提供保护？

理解检验答案不能用来诱导受访者改变意见。应预注册排除、降权或稳健性分析规则。

### 新增开放题

建议题干：

> 上述政策方案中，哪一点最可能影响您家庭的决定？是否还有问卷没有涉及的重要条件？

开放题用于发现遗漏机制，不直接自动转成Agent参数。

### 后台必须保存的元数据

- 匿名respondent_id；
- survey_wave；
- questionnaire_version；
- start_time、end_time和各情景停留时间；
- 设备和浏览器类别（仅在伦理与隐私说明允许时）；
- 随机区组、任务顺序和分配概率；
- 情景计算公式版本；
- 中断、返回和修改记录；
- 注意力/理解检验结果。

## 4. 题项到ABM的暂定映射

| 问卷信息 | 不应如何处理 | 建议处理 |
|---|---|---|
| 人口、住房、设备 | 独立抽取每个边际分布 | 保留联合记录，重抽样或生成潜类别/合成家庭 |
| TPB与政策评价题 | 每题直接标准化为参数 | 先验证测量模型，再形成潜变量后验得分或类型 |
| 实际行为矩阵 | 把意愿当实际行为 | 建立HAB/QTB/EIB/IFB基线状态和可行集 |
| 随机政策情景 | 比较固定顺序下的原始均值 | 使用混合效应/选择模型估计属性效应和异质性 |
| 社会接触人数 | 顶端区间随意赋值并线性缩放 | 保存原始类别，比较不同中点/分布假设 |
| “不知道” | 自动填0.5 | 保留不确定、插补或作为独立状态处理 |
| 7天/30天响应 | 直接解释为长期动态更新 | 仅作为持续时间条件响应，动态规则需另行验证 |

## 5. 建议的实际操作顺序

### 第一步：冻结v12

保留v12作为历史原型，不在原文件上继续叠加。复制为新版本后修改，并记录版本说明。

### 第二步：建立题项登记表

为每个题项建立以下字段：

```text
question_id
module
construct
variable_role
source
original_wording
chinese_wording
adaptation_reason
response_scale
coding
skip_logic
abm_target
survey_wave
validation_role
evidence_status
```

### 第三步：先完成A–E常规模块

在政策实验之前，先确定家庭可行集、实际行为、心理机制和政策评价背景。否则情景响应无法解释。

### 第四步：单独设计F政策实验表

不要直接在HTML里手工拼情景。先在独立表格中定义属性、水平、禁止组合、任务、区组、随机顺序和分配概率，经统计检查后再写入电子问卷。

### 第五步：认知访谈

建议分阶段进行：

1. 5–8人检查家庭设备、行为和政策词语理解；
2. 修改后再用5–8人重点测试政策组合、个性化账单和公平/可信度题；
3. 记录受访者如何理解“惩罚、补贴、协调、一致、参与、不适用”等词；
4. 不只询问“题目是否清楚”，应让受访者复述题意和作答过程。

### 第六步：小规模技术预测试

检查：跳题、随机分配、移动端显示、任务顺序、数据字段、缺失、重复提交、计算版本和JSON/后台数据一致性。

### 第七步：统计预测试

检验：题项分布、天花板/地板效应、量表结构、构念区分度、情景属性平衡、任务顺序效应、产品适用性和答题疲劳。未经该步骤，不把题目均值固化为Agent参数。

## 6. 修订完成的最低验收标准

新版本只有同时满足以下条件，才建议进入正式预测试：

1. 每个题项都有明确变量角色和ABM用途；
2. 已补足家庭能源决策角色、住房产权和关键行为约束；
3. 已测量至少一组明确时间窗口的既有实际行为；
4. HAB、QTB、EIB、IFB不再被压缩成简单“节电/购买”二分；
5. 态度、规范、控制感等不会通过单题直接充当参数；
6. 政策情景由实验设计表随机生成，不再固定顺序全答；
7. 每个情景明确区分政策评价、支持、参与和行为响应；
8. 所有个性化计算参数均有来源、地区、年份和版本；
9. “不知道、不适用、无法实施、不愿回答”被正确区分；
10. 数据保存调查轮次、版本、任务顺序和随机分配信息；
11. 已确定第一轮校准、留出情景和第二轮外部验证的分工；
12. 已完成至少两轮认知访谈和一次技术预测试。

## 7. 当前修订优先级摘要

### 第一批必须执行

1. 新增家庭能源决策角色；
2. 新增产权、住房和行为可行性；
3. 用实际行为矩阵替代现有C1/C2；
4. 新增精简心理机制和政策背景模块；
5. 取消产品自由选择和情景固定顺序；
6. 将8个全答情景改成4–6个随机任务；
7. 每情景新增政策支持、有效性、公平、负担、可信度和参与题；
8. 将“节电意愿”拆成HAB、QTB和总体用电变化；
9. 将F1/F3拆分为描述性规范、命令性规范和信息影响；
10. 删除“不确定自动赋值0.5”和设备默认值1。

### 第二批完善

1. 建立题项来源登记表；
2. 核验电价、补贴、产品价格和节电率；
3. 设计随机区组和元数据；
4. 加入理解检验、答题时间和版本字段；
5. 形成第一轮校准与第二轮验证方案。

### 第三批验证

1. 认知访谈；
2. 技术预测试；
3. 统计预测试；
4. 潜变量验证；
5. 情景选择模型估计；
6. ABM参数不确定性与敏感性分析。
